# Advanced Learning Algorithms – Machine Learning Specialization

This repository contains my **notes, code implementations, and visual summaries** from the **Advanced Learning Algorithms** course in the *Machine Learning Specialization* by [Andrew Ng](https://www.andrewng.org/) and [DeepLearning.AI](https://www.deeplearning.ai/).

The course expands upon supervised learning concepts and introduces **neural networks**, **multiclass classification**, and **regularization techniques** used in modern ML systems.

---

## 📘 Course Overview

Key concepts include:

* Neural networks and forward propagation
* Activation functions (sigmoid, ReLU, tanh)
* Backpropagation and gradient computation
* Building deep models with hidden layers
* Multiclass classification
* Regularization and preventing overfitting
* TensorFlow basics for implementing neural networks
* Model debugging and performance optimization

---

## 🚀 Why this repo?

* To **deepen understanding** of how learning algorithms scale with complexity.
* To **apply neural networks** for practical supervised learning tasks.
* To **bridge the gap** between theoretical ML and real-world AI projects.
